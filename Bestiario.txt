Con los datos que hemos extraído hasta ahora, no todos los enemigos usan las 5 mecánicas avanzadas.

Yo los dividiría así:

Nivel 1 - Enemigos básicos

Solo usan:

{
  "hp": 0,
  "melee": 0,
  "defence": 0,
  "xp": 0
}


Ejemplos:

Wolf
Frost Rat
Mosqkrin
Skulkrin
Doomdark Fanatic
Midnight Lion
Ice Troll
Targ


Para estos basta:

enemy.attack()
enemy.take_damage()

Nivel 2 - Enemigos con Loot Tables

Usan:

{
  "enemy_loot_tables": true
}


Confirmados:

Bandit
Bandit Chief
Bloodwing


Ejemplo:

loot_roll = d6()

if loot_roll <= 3:
    give("Bandit Sash")
else:
    give("Lockpicks")

Nivel 3 - Enemigos con Critical/Fumble propios

Usan:

{
  "enemy_critical_effects": true,
  "enemy_fumble_effects": true
}


Confirmados:

Bandit
Bandit Chief
Bloodwing


Porque el bestiario muestra explícitamente:

Critical Hit
Fumble


para estas criaturas.

Nivel 4 - Enemigos con tablas de ataques

Usan:

{
  "enemy_attack_tables": true
}


Confirmado:

Bloodwing


Ejemplo:

1-4 Bite
5 Frostbite Dive
6 Icy Wing


Código:

roll = random.randint(1,6)


y seleccionar ataque.

Nivel 5 - Enemigos con ataques especiales

Usan:

{
  "enemy_special_attacks": true
}


Confirmado:

Bloodwing


porque tiene:

Icy Wing

Knockback
Chilled
Cannot attack next turn
